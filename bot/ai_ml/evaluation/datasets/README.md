# Golden datasets

Keep one dataset per task under `planner/`, `verification/`, or `judge/`. Use stable case IDs, record the expected output/label and a short rationale, and document source/provenance. Sanitize URLs, credentials, customer data, and other secrets. Never auto-update expected labels from model output.

If the current evaluation dataset format already exists, preserve that schema and document it here rather than inventing a second format.
